# ArRashidIslamicInstitute2026
আর-রশিদ ইসলামিক ইনস্টিটিউট (বালিকা শাখা) একটি আধুনিক ইসলামিক শিক্ষা প্রতিষ্ঠান, যেখানে কুরআনের হিফজ, তাজবিদ ও ক্বিরাতের পাশাপাশি বাংলা, ইংরেজি ও গণিত শিক্ষা প্রদান করা হয়। নিরাপদ আবাসিক পরিবেশ, অভিজ্ঞ মহিলা শিক্ষিকা ও নৈতিক শিক্ষার মাধ্যমে আদর্শ মুসলিম নারী গড়ে তোলাই আমাদের লক্ষ্য।
